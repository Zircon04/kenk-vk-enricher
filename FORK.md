# Работа с этой версией

Основа: [alexbatishchev/kenk-vk-enricher](https://github.com/alexbatishchev/kenk-vk-enricher).
История исходного проекта сохранена. Лицензия исходного кода не указана;
для дальнейшего распространения и лицензирования изменений нужно уточнение у автора.
Включённые сторонние программы и библиотеки имеют собственные условия лицензирования.

## Фото и файлы

Из папки репозитория, в обычном Windows PowerShell 5.1:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_vk_photos_only.ps1
```

По умолчанию используется профиль `my_vk` и архив `vk-export.zip` в родительской
папке репозитория. Другой архив можно передать параметром `-ZipPath`.
При первом запуске `-Init` передаётся вместе с `-SkipVideos`. При существующем
профиле выполняется повторная обработка без видео. Оригинальный ZIP не удаляется.

Полное пересоздание удаляет **папку профиля вместе со скачанными вложениями**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_vk_photos_only.ps1 -ResetProfile
Start-Process .\profiles\my_vk\index.html
```

Обёртка делает до трёх попыток; тайм-аут отсутствия изменений в логах — 10 минут.
Вывод каждой попытки сохраняется в `logs/*.combined.log`, общий журнал и итоговые
размеры файлов — в соседнем журнале запуска. Отсутствие вывода в консоли само по
себе не означает зависание. Прерывание процесса по тайм-ауту не гарантирует
сохранения всех данных текущей операции.

## Выбранные переписки и видео

ID нужно передать явно; личных списков переписок в настройках нет.
Следующий пример сначала обработает указанные переписки с видео, затем запустит
обычную обработку остальных данных без видео:

```powershell
.\run_vk_targeted_then_resume.ps1 -MessageIds '123','456' -Browser firefox -MaxResolution 480 -MaxFilesize 700M
```

`-NoResume` завершает работу после выбранных переписок. Через `powershell.exe -File`
передавайте список одной строкой: `-MessageIds '123,456'`.

Отдельный запуск с видео для всего профиля:

```powershell
.\run_vk_videos_limited.ps1 -Browser firefox -MaxResolution 360 -MaxFilesize 400M
```

Поддержаны Firefox и Chrome. Выбор формата ограничен высотой 360/480;
при отсутствии подходящего совмещённого формата видео будет пропущено.
`--max-filesize` — ограничение средствами yt-dlp, а не гарантия общего трафика
или размера каталога. Размеры потоков могут быть неизвестны заранее, а метаданные
и превью сохраняются отдельно. `-SkipPhotos` исходного скрипта отключает фотоальбомы,
но не означает строгого исключения фотографий из переписок.

Для веб-запросов Firefox требуется Python 3 (`python.exe` или `py.exe`).
Cookies берутся из локального профиля Firefox и ограничены HTTPS-доменом `vk.com`.
Видео использует авторизацию самого yt-dlp. Скрипты не обходят удалённые материалы
и ограничения доступа; ошибки 404 и недоступные вложения остаются в журнале.

## Прогресс

В отдельном окне PowerShell:

```powershell
.\vk_progress_monitor.ps1
```

Откройте `logs/vk_progress_status.html`; страница обновляется каждые 30 секунд.
Для отдельных переписок можно передать `-MessageIds '123','456'`.
Проценты отражают страницы переписок из последнего журнала, а не долю всех
скачанных вложений. После перезапуска они могут начаться заново; оценка оставшегося
времени не вычисляется. Счётчики скачанных файлов читаются с диска.

`watch_targeted_then_resume.ps1 -TargetPid <PID>` — вспомогательный наблюдатель:
он запускает обработку без видео только при доступном успешном коде завершения.
При неизвестном результате нужно проверить журнал и возобновить обработку вручную.

## Проверка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\offline-checks.ps1
```

Проверяется синтаксис, изоляция cookies, выбор переписок и запрет загрузки видео.
Тест использует вымышленные cookies и не обращается к браузеру или сети.
Профили, архивы, логи, cookies и резервные копии не предназначены для публикации.
